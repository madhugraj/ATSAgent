What changed vs today’s page
  1. One verdict (“3 things need you”) plus five one-word pills replaces five full-width question cards and the tiles.
  2. Fix list first — only actionable rows, each with an agent and a next-step link; the 17 passing checks collapse to one line.
  3. One main visual — the hand-off map, with a one-line legend and four numbers under it instead of a paragraph.
  4. One agent matrix (agent × five checks as dots, expand a row for detail) replaces the separate limits, autonomy, definitions and budget tables. Switched-off agents are hidden by default.
  5. Own page, own audience — Agent administration → Agent governance, for agent owners. Agent behaviour stays on Agent intelligence; skill supply vs demand moves to the Intelligence section.
  6. No side inspector, no prose cards — detail opens in place.
